Parte 1

Costruttori

Il costruttore inizializza gli attributi di un oggetto nel momento in cui viene creato con new. Gli esercizi sono ordinati per difficoltà crescente.

Richiami di teoria
Che cos'èUn blocco speciale della classe che inizializza gli attributi dell'oggetto appena creato con new.
RegoleStesso nome della classe (maiuscole comprese) e nessun tipo di ritorno, nemmeno void.
Costruttore di defaultSe non ne scrivi nessuno, Java aggiunge NomeClasse() senza parametri. Sparisce appena ne scrivi uno tu.
this.attributoQuando un parametro ha lo stesso nome di un attributo, this. indica l'attributo dell'oggetto.
OverloadingPiù costruttori nella stessa classe, con firme diverse: numero, tipo o ordine dei parametri.
this(...)Chiama un altro costruttore della stessa classe. Deve essere la prima istruzione.
public class Studente {
    private String nome;
    private int eta;

    public Studente() {                       // costruttore senza parametri
        nome = "Anonimo";
        eta = 14;
    }

    public Studente(String nome, int eta) {   // overloading: firma diversa
        this.nome = nome;                     // this.nome = attributo, nome = parametro
        this.eta = eta;
    }
}

// nel main
Studente a = new Studente();               // usa il primo costruttore
Studente b = new Studente("Anna", 16);     // usa il secondo
